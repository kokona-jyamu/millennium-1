## 概要
実在する企業からの依頼をもとに、要件や構成を整理した上で、
HTML / CSS / JavaScript を用いてコーポレートサイトを一から作成しました。

初期設計段階ではノーコードツールを用いて構成の検討を行い、
その後 Visual Studio Code を使用してコーディングを行っています。

## 使用技術
- HTML
- CSS（Flexbox）
- JavaScript（jQuery）
- GitHub Pages

## 工夫点
- レスポンシブ対応
- フォームバリデーションの実装
- 全体のUI・デザインの統一感を意識した設計

## 制作期間
約4週間

企業のご担当者様と相談しながら要件を調整し、
